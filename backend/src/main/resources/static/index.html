▶️ YouTube 解析（yt-dlp）

加载中…

留空自动探测（手动路径 → 应用托管安装 → 系统 PATH → 常见路径）；可填二进制的完整路径、或其所在目录，填写后随本页「保存设置」一并生效（入口在存储位置卡）
加载中…

留空自动探测（手动路径 → 应用托管安装 → 系统 PATH → 常见路径）；可填二进制的完整路径、或其所在目录，随本页「保存设置」一并生效

yt-dlp 解析 YouTube 需要 Deno 作为 JavaScript 运行时：缺失时只能拿到故事板（mhtml）伪格式、会报「格式不可用」。检测到 Deno 后，应用会在每次调用 yt-dlp 时自动把它的路径传过去，不依赖系统 PATH。

无法直连 YouTube 时填，如 http://127.0.0.1:7890；仅 yt-dlp 解析请求走此代理，媒体下载走引擎的系统代理

也可手动安装：到 github.com/yt-dlp/yt-dlp 的 Releases 下载对应系统的官方单文件二进制（Windows: yt-dlp.exe / Mac: yt-dlp_macos / Linux: yt-dlp_linux），放到任意目录后在上方填写路径，或加入系统 PATH 后刷新本页。

解析报错（如「格式不可用」）时点状态旁的「更新」可拉取官方最新版：更新会把最新版下载到本应用托管目录；若当前命中的是手动路径或系统 PATH，定位顺序不变，状态可能仍显示那个来源。

🌐 工具安装代理

ffmpeg / yt-dlp / Deno / Gopeed 的「一键安装」都从官方源下载（GitHub 等），部分网络直连不通、TLS 握手会被掐；填一个代理即可，填一次各处共用，支持 http:// 与 socks5://，随本页「保存设置」生效（点各卡的安装按钮时也会先自动保存本页设置再安装）
